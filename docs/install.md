# Install Stremio Origin on an Android TV

Use the Downloader app. About two minutes.

## Steps
1. **On the Android TV, install Downloader** (by AFTVnews) from the store.
2. **Open Downloader** and type the code **2557412** in the address box, then choose **Go**.
3. **Install.** If Android asks, allow Downloader to install unknown apps, then go back and install again.
4. **Open Stremio Origin** and sign in with your Stremio account.

## Good to know
- **Updating:** update in the app.
